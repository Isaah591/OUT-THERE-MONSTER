# OUT THERE — Monster Reconstruction (Blender)

A from-scratch Blender rebuild of the OUT THERE monster. The original Roblox screenshots
(`references/roblox_original_*`) define the anatomy and silhouette; the R08 remaster
screenshots (`references/r08_remaster_surface_*`) were used **only** as the target for
surface, wound and material quality. All geometry is generated by Python, so every
proportion is a named, editable number.

## Rebuilding

Blender 5.0.1 is used as the `bpy` Python module (PyPI, Python 3.11) because the cloud
environment cannot reach download.blender.org. Cycles CPU works; EEVEE/Workbench do not
(no GPU / libEGL in the container). The scripts also run inside a normal Blender install.

```bash
python3.11 -m venv bvenv && bvenv/bin/pip install bpy pillow
```

```bash
bvenv/bin/python scripts/build_monster.py --stage final
```

```bash
bvenv/bin/python scripts/render_views.py model/out_there_monster.blend model/renders front side_r threequarter head mouth wound_arm
```

```bash
bvenv/bin/python scripts/bake_export.py model/out_there_monster.blend model/roblox_export 1024
```

## How the geometry is constructed

- **Units / axes:** metres, Z up, monster faces −Y. Monster's right (−X) carries the long arm.
- **Body:** every body part is a *loft* — chamfered-box cross-sections placed along a
  spine/limb path and bridged into one closed mesh. This keeps the original's blocky,
  angular identity while making limbs read as connected anatomy rather than stacked boxes.
  Climber proportions: 1.2 m shoulder girdle tapering to a 0.54 m waist, limbs 0.27–0.35 m thick.
- **Pose:** spine leans ~25° forward with an angular trapezius/upper-back ridge. The long
  arm hangs from the shoulder, then the elongated forearm swings out ~45° to plant a club
  hand flat on the floor (2.6 m long vs 1.3 m for the short arm, which ends in a bloody
  stump at knee height).
- **Head:** compact cranium (no snout) with boolean-cut eye sockets. The **Jaw** is its own
  object hinged at the rear of the cranium base and hangs open **55°** with a 7° broken-hinge
  sag. Only the rear 0.21 m of the jaw (the hinge, buried in the neck) overlaps the body —
  the chin, lower teeth and gums are clear of the chest (checked with a BVH overlap test
  on every build). Lower teeth and gums are parented to the jaw.
- **Teeth:** ~45 individually generated teeth: 5–6-sided irregular sections, bent, twisted,
  uneven spacing, missing slots, crowded second-row teeth, and four tip types (fang,
  fractured, chipped-blunt, broken stump). A per-vertex attribute drives grime and dried
  blood creeping from the lumpy gum ridges.
- **Shell surface:** simple subdivision + stepped Voronoi/cloud displacement → faceted,
  plate-like corroded surface, flat-shaded.
- **Wounds (shallow tissue):** each is two stacked boolean cuts with irregular torn
  outlines: a wide 1 cm peel that strips the rust skin to a darker under-layer, and inside
  it a 3–4 cm tear whose walls show the shell thickness and whose floor is dark fibrous
  tissue. Tissue bundles and split, peeled-back shell lips are added on top. 16 wounds,
  ~65 small chips, placed by projecting art-directed positions onto the surface.
- **Blood:** a painted `blood` vertex attribute (wounds, mouth rims, stump, rod entries,
  running further downward) masked by noise in the shaders — old, dark stains only.
- **Rods:** flat bars projected onto the finished surface so they stay embedded.

## Polygon budget

~28,200 triangles total. Largest: long arm ~5k, torso ~4.5k, legs ~2.8k each,
short arm ~2.6k, cranium ~1.6k, jaw ~1.3k, teeth ~1.6k, gums ~1k, rods ~0.4k.
Export groups for Roblox are listed (with counts) in the bake log and `docs/ROBLOX_IMPORT.md`.

## Known limitations

- No armature, weights or animation yet.
- Materials are procedural; Roblox only sees the baked 1024² maps, which lose some of the
  finest speckle and the AO/edge-wear terms are baked in (static lighting assumptions).
- Cheek membranes were generated for the current jaw angle; re-opening the jaw needs
  `JAW_OPEN_DEG` changed and a rebuild (or a shape key once rigged).
- The rods are a single mesh spanning several body parts.
