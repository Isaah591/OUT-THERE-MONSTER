# OUT THERE — Monster Reconstruction (Blender)

A from-scratch Blender rebuild of the OUT THERE monster. **Current direction:** recreate the
Astra R08 design (`references/r08_reference_sheet_primary.webp`) as faithfully as possible —
proportions, silhouette, head, limbs, materials, wounds, rods and teeth — with exactly one
intentional change: the lower jaw is forced/broken open into a Pac-Man-like wedge.
All geometry is generated by Python, so every proportion is a named, editable number and
the model rebuilds in ~15 s.

## Rebuilding

Blender 5.0.1 is used as the `bpy` Python module (PyPI, Python 3.11) because the cloud
environment cannot reach download.blender.org. Cycles CPU works; EEVEE/Workbench do not
(no GPU / libEGL in the container). The scripts also run inside a normal Blender install.

```bash
python3.11 -m venv bvenv && bvenv/bin/pip install bpy pillow
```

```bash
bvenv/bin/python scripts/build_monster.py --stage final
```

```bash
STUDIO=dark bvenv/bin/python scripts/render_views.py model/out_there_monster.blend model/renders front threequarter side_r head_front mouth wound_shoulder wound_arm wound_leg
```

```bash
bvenv/bin/python scripts/make_sheets.py model/renders references
```

## How it is built

- **Units / axes:** metres, Z up, monster faces −Y. Monster's right (−X) carries the long arm.
- **Body (R08):** lofts of chamfered box sections along limb/torso paths, with mild
  irregularity and a light low-poly chisel. A big near-vertical box torso with a rounded
  upper back; the head sits directly on its top (a short hidden neck block ties them). The
  upper chest recedes slightly behind the jaw (invisible from the front) so the forced-open
  jaw can hang in front of it. Chunky box arms whose tops form the shoulder blocks; thick
  straight legs on blocky feet; slight stance asymmetry.
- **Head (R08):** a compact, deep barrel built from three stacked rust strata (each band
  overhangs the next), nodding forward ~9°. Square, dark, recessed sockets with tiny red
  square eyes.
- **Jaw / mouth (the one intentional change):** the lower jaw is as long as the head is deep
  and is forced open **58°** about its rear hinge, so the profile is a '<' / Pac-Man wedge
  with the chin dropping to 1.90 m while the upper skull and upper-jaw projection stay as in
  R08. Knuckle hinges (the right one split and sagging 5°), torn membranes bridging only the
  rear third of the wedge, taut tendons straining across it (one snapped per side), palate
  ridges, tongue and ribbed throat. Lower teeth ride the jaw and are re-aimed up into the
  mouth. Teeth, gums and tongue are checked against the chest on every build (BVH overlap:
  0); only the hinge itself is anchored into the torso top.
- **Teeth:** 32 big plank teeth (17 upper, 15 lower) in deliberate rows — rectangular sections,
  uneven lengths and tilts, some snapped, chipped, slabbed or broken to stumps, the odd gap,
  one tooth per row rammed in at a bad angle. Yellowed, decaying, dark grime and dried blood at
  the gum line; smooth enamel with crisp fracture edges.
- **Damage — localized, R08 style:** *bark peels* tear the rust skin away in two stepped
  strata (dark old-rust floor, lighter torn edges, a curling lip or two), concentrated on
  forearms, knees, shins and the torso sides; the chest front stays mostly intact. A few
  shallow *flesh tears* at stress points (elbow, forearm, knee, shin, shoulder, flank, cheek):
  a split through the shell over a corrugated fibrous tissue sheet 1–2 cm below the surface,
  with splinters over the opening; a rod is driven into the shoulder wound. Wounds are placed
  by ray-casting onto the intended side of each limb.
- **Materials:** granular, stone-like rust (multi-scale mottling, dense dark speckle, per-facet
  tint, AO grime in crevices, worn edges, vertical streaks, ground dirt), a darker old-rust
  under-layer, dull dark-red fibrous flesh, rusted flat-bar rods, and a painted `blood`
  attribute for old stains around wounds, mouth, stump and rod entries.

## Triangle budget (v3)

~38,700 triangles total. Torso 8.6k, long arm 6.7k, skull 4.5k, legs 3.8k / 3.4k, short arm
3.5k, jaw 2.8k, teeth ~2.9k, gums/tissue/interior/hinges/rods/eyes the rest. Every part and
every export group is far below Roblox's 20,000-triangle MeshPart limit.

## Known limitations

- No armature, weights or animation yet.
- Materials are procedural; Roblox only sees baked 1024² maps. The v3 bake/export has not
  been run yet (deliberately — review first).
- Mouth-corner membranes are generated for the current jaw angle; changing `JAW_OPEN_DEG`
  needs a rebuild (or shape keys once rigged).
- Rods are one mesh spanning several body parts.
