# OUT THERE — Monster Reconstruction (Blender)

A from-scratch Blender rebuild of the OUT THERE monster, driven by the original Roblox
screenshots in `references/`. All geometry is generated by Python scripts, so every
proportion is a named, editable number.

**Status: Stage 1 — silhouette blockout, awaiting approval.** No detail sculpting, wounds,
teeth texturing or final materials yet; colours in the blockout are flat placeholders.

## Layout

| Path | Contents |
|---|---|
| `references/` | Original Roblox screenshots (primary anatomy reference) |
| `scripts/build_monster.py` | Procedural builder → `blockout/out_there_monster_blockout.blend` |
| `scripts/render_views.py` | Adds studio lights/cameras, renders review views (Cycles CPU) |
| `scripts/make_sheets.py` | Builds review sheets and reference-vs-blockout comparisons |
| `blockout/` | Blockout `.blend` and `renders/` |

## Environment

Blender 5.0.1 is used as the `bpy` Python module (from PyPI, needs Python 3.11), because the
cloud environment cannot reach download.blender.org. Cycles CPU rendering works; EEVEE and
Workbench do not (no GPU / libEGL in the container). The scripts also run in normal Blender:

```bash
blender -b -P scripts/build_monster.py
```

```bash
blender -b -P scripts/render_views.py -- blockout/out_there_monster_blockout.blend blockout/renders front side_r threequarter
```

With the `bpy` module instead:

```bash
python3.11 -m venv bvenv && bvenv/bin/pip install bpy pillow
```

```bash
bvenv/bin/python scripts/build_monster.py
```

## Construction (blockout)

- Units: metres, Z up, monster faces -Y. Monster's right (-X) carries the long arm.
- Body parts are **lofted chamfered-box tubes** (`loft()`): cross-sections placed along a
  spine/limb path and bridged, giving connected, blocky-but-anatomical forms instead of
  stacked primitives. Small vertex jitter breaks perfect symmetry.
- **Head:** compact cranium (no snout) with a flat palate; eye sockets are boolean-cut.
  The **Jaw** is a separate object hinged near the back of the cranium base, hollowed into
  a trough, and opened by `JAW_OPEN_DEG` (50°) with a `JAW_BROKEN_ROLL_DEG` (7°) sag.
  Lower teeth are parented to the jaw, so re-opening the jaw is a single rotation.
- Throat wall + cheek membranes make the mouth a closed, dark cavity.
- Hardware rods are flat bars swept along polylines.
- ~1,860 triangles total.
